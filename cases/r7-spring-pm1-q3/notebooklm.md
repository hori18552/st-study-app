## 3. カスタマイズ欄に貼る指示文

```
令和7年度春期ITストラテジスト試験 午後Ⅰの「問3（ドラッグストアC社）」だけを扱ってください。問1と問2には触れないでください。

聞き手は、ITストラテジスト試験の受験者です。通勤中に聴いて、ケースの全体像をつかみたいと考えています。

次の順番で話してください。
1. K地域の環境：どんな住民がいて、何を求めているか
2. C社のこれまでの4つの戦略（出店・調剤薬・小売売場の運営・商品開発）と、それぞれの狙い
3. 他チェーンの進出と、調剤売場・小売売場の課題
4. 新たな方針（LTVの拡大、店舗とオンラインの融合によるCXの向上）
5. 健康生活アプリの3つの機能と、服薬指導補助システムが、それぞれどの課題・ニーズ・強みに対応しているか
6. 設問1〜4を1問ずつ取り上げ、解答例と「問題文のどこが根拠になるか」を説明する
7. 採点講評で指摘された「間違えやすいポイント」と、ITストラテジストとして身につけるべき考え方

専門用語（LTV、CX、小商圏、PB商品、服薬指導など）は、出てきたときにひと言で説明してください。
「環境 → 戦略 → 課題 → 施策 → システム」のつながりを、何度も振り返りながら話してください。
```
